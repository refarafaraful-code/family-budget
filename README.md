# התקציב המשפחתי

אפליקציית ווב פשוטה לניהול תקציב ההוצאות החודשי של המשפחה. בכל 1 לחודש מגדירים כמה כסף נשאר להוצאות (אחרי החשבונות הקבועים), כל בני המשפחה רושמים הוצאות מהטלפון, וכולם רואים בזמן אמת כמה נשאר.

- **אירוח:** GitHub Pages (חינם)
- **נתונים:** Firebase Firestore (חינם בהיקף של משפחה)
- **כניסה:** בלי סיסמאות. מי שיצר את המשפחה שולח לשאר קישור הצטרפות סודי, וכל מכשיר זוכר מי משתמש בו.

## הקמה (פעם אחת, כ-10 דקות)

### 1. Firebase
1. נכנסים ל-[Firebase Console](https://console.firebase.google.com) ויוצרים פרויקט (אפשר לוותר על Google Analytics).
2. **Build > Authentication > Get started > Sign-in method:** מפעילים **Anonymous**.
3. **Build > Firestore Database > Create database:** בוחרים אזור (למשל `eur3`) ו-**Production mode**.
4. בלשונית **Rules** של Firestore מדביקים את התוכן של `firestore.rules` ולוחצים **Publish**.
5. **Project settings > Your apps > `</>`:** רושמים Web App ומעתיקים את `firebaseConfig` לקובץ `firebase-config.js`.
6. **Authentication > Settings > Authorized domains:** מוסיפים `<שם-משתמש>.github.io`.

### 2. GitHub Pages
בריפו: **Settings > Pages > Source: Deploy from a branch**, ענף `main`, תיקייה `/ (root)`. אחרי דקה האתר זמין בכתובת `https://<שם-משתמש>.github.io/family-budget/`.

### 3. המשפחה
1. אבא פותח את האתר, ממלא את שמות בני המשפחה ולוחץ "יצירת המשפחה".
2. בתחתית המסך לוחצים "קישור הצטרפות לבני המשפחה" ושולחים בוואטסאפ לכל אחד.
3. בטלפון: בתפריט הדפדפן בוחרים "הוספה למסך הבית", וזה נראה כמו אפליקציה.

## איך זה עובד
- רק מי שמופיע ראשון ברשימה (אבא) יכול להגדיר ולעדכן את התקציב.
- כל אחד יכול למחוק הוצאה שהוא רשם; אבא יכול למחוק כל הוצאה.
- אפשר לדפדף לחודשים קודמים ולראות לאן הלך הכסף לפי קטגוריה או לפי מי.

## אבטחה
הקוד בריפו ציבורי, אבל הנתונים לא: הם ב-Firestore, ונגישים רק למי שמחזיק בקוד המשפחה מקישור ההצטרפות (24 תווים אקראיים). לא לשתף את הקישור מחוץ למשפחה. מי שאיבד אותו יכול לבקש מבן משפחה אחר.
